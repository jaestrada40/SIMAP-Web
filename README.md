# SIMAP-Web

Portal para monitorear y actualizar, de uno en uno, los portales WordPress en OpenShift.

- `src/`: frontend (React, TanStack Router/Start, Tailwind, shadcn).
- `backend/`: API (Node + TypeScript + Fastify + Postgres).
- `PROYECTO.md`: objetivo, estado y reglas. `MANUAL.md`: manual de cada pantalla.

Desarrollo: ver `PROYECTO.md`.
